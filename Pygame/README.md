# Pygame Learning & Practice

A personal repository dedicated to learning and practicing Pygame game development.

## 📂 Contents
*   `Pygame_Demo.py`: A basic demo featuring window creation, an event loop, and WASD keyboard controls to move a rectangle.

## 🛠️ Prerequisites
*   Python 3.x
*   Pygame (Install via: `pip install pygame`)

## 🚀 How to Run
Make sure Python and Pygame are installed. 
Run the following command in your terminal:
```bash
python Pygame_Demo.py

## 📁 Game Assets

All the necessary image and audio assets (sprites, backgrounds, music, etc.) required to run the games in this folder are located in the **`../Assets`** folder.

**Important Note:**
If you download this specific `Pygame` folder to run the code, you must also download the `Assets` folder from the root directory and place it next to the `Pygame` folder. The code uses relative paths to load these files, so failing to maintain this directory structure may result in `FileNotFoundError`.
