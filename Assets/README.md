# Game Assets Directory

This folder contains all the graphical and audio assets required to run the **Airplane Battle** game.

## 📁 File List
- `me1.png`: Player airplane sprite
- `enemy1.png`: Enemy airplane sprite
- `bullet1.png`: Bullet sprite
- `background.png`: Game background image
- `bgm.wav`: Background music

## ⚠️ Important Note
The main Python script (`The Complete Version of Airplane Battle.py`) uses relative paths to load these assets. 

If you are downloading this project, please ensure that **this `assets` folder is placed in the exact same directory as the Python script**, and do not rename the files, otherwise the game will throw a `FileNotFoundError`.
