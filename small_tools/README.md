# Small Tools

This directory contains a collection of lightweight, standalone utility scripts designed to solve specific tasks or automate simple workflows.

## 📂 Contents

*   `GPA Calculation System.py`: A utility script to calculate the Grade Point Average (GPA) based on user input credits and grades.
*   `Words test project.py`: A vocabulary testing or typing practice program, designed to help memorize or test word spellings.

## 🚀 Usage

Each tool is an independent Python script. To run any of them, make sure you have Python installed, then execute the specific file in your terminal. For example:
```bash
python "GPA Calculation System.py"
