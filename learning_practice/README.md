# Learning Practice

This directory contains various Python scripts and notes for my ongoing learning and practice in different technical domains.

## 📁 Contents

*   `Database grammar.py` : Practice scripts and syntax notes for database operations.
*   `Django note` : Notes and reference materials for Django web development.
*   `Docker Note.py` : Personal notes, cheat sheets, or automation scripts related to Docker commands.
*   `Mat Grammar.py` : Syntax cheat sheet and practice scripts for Matplotlib data visualization.
*   `NP Grammar.py` : Syntax cheat sheet and practice scripts for NumPy array operations.
*   `PD Grammar.py` : Syntax cheat sheet and practice scripts for Pandas data manipulation.
*   `Pygame grammar.py` : Practice code and syntax reference for Pygame game development.

## 🎯 Purpose

The goal of this folder is to serve as a sandbox for testing new concepts, storing quick reference notes, and keeping track of my learning progress across different technologies.
